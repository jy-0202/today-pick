# Today Pick

## 조건 기반 맛집 탐색 및 추천 웹 서비스

사용자의 **지역, 음식 카테고리, 가격대, 분위기 등의 조건을 기반으로 음식점을 탐색**하고,
상세 정보와 메뉴·리뷰 및 지도 위치를 확인할 수 있도록 구현한 Spring Boot 기반 웹 서비스입니다.

조건 검색과 지도 기반 탐색 기능을 중심으로 구현했으며,
향후 자연어 입력을 기존 조건 검색과 연결하는 AI 추천 기능으로 확장할 수 있도록 기본 구조를 구성했습니다.

## 2. 주요 기능

### 조건 기반 맛집 검색

사용자가 선택한 조건을 기반으로 음식점을 조회합니다.

- 지역
- 음식 카테고리
- 가격대
- 상세 태그
- 음식점명
- 메뉴명

음식점명뿐만 아니라 메뉴명도 검색 대상에 포함하여 원하는 음식이나 메뉴를 기준으로 음식점을 찾을 수 있도록 구성했습니다.

### 음식점 상세 조회

검색 결과에서 음식점을 선택하면 상세 정보를 확인할 수 있습니다.

- 음식점 기본 정보
- 음식 카테고리
- 주소
- 메뉴 및 가격
- 리뷰
- 평균 평점
- 리뷰 수
- 지도 위치

### Kakao Map 기반 음식점 탐색

Kakao Maps JavaScript API를 이용하여 음식점 위치를 지도에서 확인할 수 있도록 구현했습니다.

또한 사용자가 지도를 이동하면 **현재 지도 영역에 포함되는 음식점만 사이드바에 표시**하고 결과 개수도 함께 갱신하도록 구현했습니다.

```text
지도 이동
    ↓
현재 지도 영역(bounds) 확인
    ↓
영역 내부 음식점 판별
    ↓
사이드바 음식점 목록 갱신
    ↓
현재 결과 개수 갱신
```

### AI 추천 확장 구조

자연어 기반 추천 기능을 향후 추가할 수 있도록 다음 기본 구조를 구성했습니다.

- AI 추천 입력 화면
- 추천 요청을 처리하기 위한 Service 구조
- 추천 결과 전달을 위한 DTO 구조

현재 실제 AI API 또는 추천 모델 연동은 구현하지 않았으며,
향후 자연어에서 사용자의 추천 조건을 추출하여 기존 조건 검색 기능과 연결하는 방향으로 확장할 예정입니다.

## 4. 애플리케이션 구조

Spring Boot의 계층 구조를 기준으로 역할을 분리했습니다.

```text
Client
   ↓
Controller
   ↓
Service
   ↓
Repository
   ↓
MySQL
```

각 계층은 다음 역할을 담당합니다.

| 계층 | 역할 |
|---|---|
| Controller | 사용자 요청 처리 및 화면 연결 |
| Service | 음식점 조회 및 비즈니스 로직 처리 |
| Repository | JPA 기반 데이터베이스 접근 |
| DTO | 계층 및 화면 간 데이터 전달 |
| Entity | 데이터베이스 테이블과 객체 매핑 |
| Thymeleaf | 서버 데이터를 이용한 화면 렌더링 |
| JavaScript | 지도 및 사용자 인터랙션 처리 |

## 5. 주요 구현 내용

### 조건 검색

여러 검색 조건을 이용하여 사용자가 원하는 음식점을 탐색할 수 있도록 구성했습니다.

```text
사용자 검색 조건
    ↓
Controller
    ↓
Service
    ↓
Repository
    ↓
조건에 해당하는 음식점 조회
    ↓
검색 결과 화면
```

지역·카테고리·가격대·태그 등 여러 조건을 조합할 수 있도록 구성하고,
음식점명과 메뉴명을 이용한 검색도 함께 제공합니다.

### 음식점 상세 데이터 연동

음식점 상세 화면에서는 음식점 정보뿐만 아니라 메뉴와 리뷰 데이터를 함께 조회하여 표시합니다.

리뷰 데이터를 이용하여 평균 평점과 리뷰 수를 제공하고,
관련 데이터를 하나의 상세 화면에서 확인할 수 있도록 구성했습니다.

### 지도와 음식점 목록 연동

지도에서 보이는 음식점과 사이드바의 검색 결과가 서로 다른 정보를 보여주지 않도록
지도 영역과 음식점 목록을 동기화했습니다.

Kakao Map의 지도 이동 이벤트가 완료되면 현재 영역을 확인하고,
각 음식점의 좌표가 해당 영역에 포함되는지를 기준으로 목록을 다시 표시합니다.

## 6. Troubleshooting

### 지도 이동 후 사이드바 목록 불일치

#### 문제

Kakao Map에서 지도를 이동하면 현재 지도 영역에 포함되는 음식점 개수는 변경되었지만,
사이드바에는 기존 전체 음식점 목록이 계속 표시되는 문제가 있었습니다.

이 때문에 지도에서 보이는 음식점과 사용자가 목록에서 확인하는 음식점이 서로 일치하지 않았습니다.

#### 원인

지도 영역이 변경된 뒤 결과 개수는 갱신하고 있었지만,
사이드바의 각 음식점 카드에 동일한 지도 영역 기준이 적용되지 않고 있었습니다.

#### 해결

Kakao Map의 지도 이동 완료 시점에 현재 지도 영역을 가져오고,
각 음식점 좌표가 해당 영역 안에 포함되는지 확인하도록 수정했습니다.

```text
지도 이동 완료
    ↓
현재 지도 영역 확인
    ↓
음식점 좌표 확인
    ↓
지도 영역 포함 여부 판단
    ↓
해당 음식점 카드 표시 / 숨김
    ↓
결과 개수 갱신
```

사이드바 카드와 결과 개수가 동일한 지도 영역을 기준으로 동작하도록 처리했습니다.

#### 결과

지도 이동 후 현재 화면에 포함된 음식점만 사이드바에 표시되며,
표시된 음식점 수와 결과 개수도 일치하도록 개선했습니다.

이 과정에서 지도에 정보를 표시하는 것뿐만 아니라
**지도 상태와 화면의 검색 결과를 동일한 기준으로 관리하는 것이 중요하다는 점을 확인했습니다.**

## 8. 향후 개선

### 현재 위치 기반 검색

브라우저의 위치 정보를 이용하여 현재 위치 주변의 음식점을 조회하고,
사용자와 음식점 간 거리를 계산하여 가까운 순서로 정렬하는 기능을 추가할 예정입니다.

### 지도 탐색 기능 개선

현재 구현된 지도 영역 기반 음식점 목록 동기화에
지역·카테고리·가격대 등의 검색 조건을 함께 적용하여
지도 이동과 조건 검색을 결합한 탐색 기능으로 개선할 예정입니다.

### AI 기반 자연어 추천

현재 구성한 AI 추천 화면 및 Service·DTO 구조를 기반으로
자연어 입력을 실제 추천 기능과 연결하는 것을 향후 확장 목표로 두고 있습니다.

```text
사용자 자연어 입력
    ↓
추천 조건 분석
    ↓
지역 / 음식 / 가격 / 분위기 등의 조건 추출
    ↓
기존 조건 검색 기능과 연계
    ↓
추천 음식점 제공
```

음식점·메뉴·리뷰 데이터를 활용할 수 있는 추천 방식을 검토하고,
실제 서비스 기능과 연결 가능한 형태로 확장할 예정입니다.

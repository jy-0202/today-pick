# todayPick

사용자의 지역, 음식 취향, 가격대, 분위기 등의 조건을 기반으로 맛집을 탐색하고 추천하는 웹 서비스입니다.

## 주요 기능

- 지역 기반 맛집 조회
- 음식 카테고리 및 가격대 조건 검색
- 상세 조건(Tag) 기반 검색
- 음식점명 및 메뉴명 통합 검색
- 음식점 상세 정보 조회
- 메뉴 및 리뷰 조회
- 리뷰 평균 평점 및 리뷰 수 제공
- Kakao Map 기반 음식점 위치 탐색
- AI 추천 UI 및 임시 조건 분석

## 기술 스택

- Java 21
- Spring Boot 3.5
- Spring Data JPA
- Thymeleaf
- MySQL
- HTML / CSS / JavaScript
- Kakao Maps JavaScript API
